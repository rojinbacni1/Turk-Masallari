## 📖 Proje Hakkında

**Dilden Dile**, Türk masal, fıkra ve destan anlatılarını (Keloğlan, Nasreddin Hoca, Dede Korkut vb.) geleneksel motiflerle zenginleştirilmiş kullanıcı dostu bir arayüzde derleyen tek sayfalık etkileşimli bir web platformudur.

### Temel Özellikler:
* **Geleneksel Görsel Tasarım:** Kilim motifleri, lale vektörleri ve sıcak zemin renkleriyle zenginleştirilmiş özgün arayüz.
* **Gece / Gündüz Modu:** Kullanıcının okuma konforunu artıran dinamik tema değiştirme mekanizması.
* **Etkileşimli Okuma Araçları:** Yazı boyutunu büyütme/küçültme butonları ve rastgele masal getirme fonksiyonu.
* **Kişisel Kitaplık Durumları:** Masalları "Devam ettiklerim", "Bitirdiklerim" ve "Favorilerim" olarak işaretleme ve dinamik sayaç takibi.
* **Harici Kütüphanesiz Mimari:** Tamamen saf semantik HTML, içsel CSS ve içsel JavaScript kullanılarak tek dosyada çalışacak şekilde kodlanmıştır.
